## 2. 转换规则（第1–7章，脚本处理）
1. `\[ ... \]` 且整段在同一行 → 变成独占一行的 `$$ ... $$`，上下各留一个空行。
2. `\[ ... \]` 跨多行 → 合并成一行，再按上一条处理；若原段落在 `>` 引用块里，**把公式移出引用块**（放在引用块下面，不再带 `>`），否则 GitHub 可能不渲染。
3. `\( ... \)` → `$ ... $`（全库只有个位数）。
4. 表格单元格内的 `\[ ... \]` → 改为行内 `$ ... $`（表格里不能用独立公式）。
5. 表格单元格内、`$...$` 里的竖线：`\|`、`|` 一律改成 `\Vert`、`\vert`，避免被当成列分隔符。
6. `$` 紧邻空格的（`$ x$`、`$x $`）去掉空格——GitHub 要求 `$` 内侧不留空格。
7. 正文里 `$...$` 之外、未转义的 `_` 和 `*`：如果会变成斜体/粗体（例如 `source_id`、`MINORIZATION_CORRECTED`、`x.y_z`），用反引号包成代码或转义；数学里的 `_` 不动。
8. 不动代码块（```lean）、不动链接 URL、不动 `#锚点`（标题文字不改）。
