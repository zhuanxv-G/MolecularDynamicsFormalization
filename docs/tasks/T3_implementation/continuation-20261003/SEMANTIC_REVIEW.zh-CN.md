## 逐目标判定

| 原目标 | 判定 | 对应与必要边界 |
| --- | --- | --- |
| matrixKineticGoal（K1） | 接受 | 正坐标质量使整体矩阵逆等于倒数对角，得到教材二次型的一半。不是奇异矩阵的无条件公式。 |
| velocityEnergyGoal（E1） | 接受 | 代入p=Mv，H等于式(1.4)的坐标速度能量；允许任意实质量是纯代数的较强结论。 |
| particleEnergyGoal（P1） | 接受 | 沿已证明的粒子/坐标展开，势能仍作用于展开后的原位置，粒子动能使用每个粒子的欧氏范数。 |
| coordinateGradientGoal（G1） | 接受 | 有限和真实Frechet导数证明给出HasGradientAt；质量是固定常数，未把目标梯度藏进前提。 |
| matrixGradientGoal（G1） | 接受 | 正质量把坐标p/m与M⁻¹p连接；未用非负质量替代可逆条件。 |
| positionGradientGoal（G2） | 接受 | 明确要求U在q可微，给出位置切片真实HasGradientAt。 |
| positionTotalGradientGoal（G2） | 接受 | 仅是mathlib总gradient的加常数恒等式。无可微前提，因此独立登记，不能当成物理偏导证据。 |
| vectorFieldGoal（V1） | 接受 | 两个欧氏切片给出静态向量场(M⁻¹p,-gradient U q)。物理Hamilton方程解释另需U可微；没有假定乘积相空间的内积结构。 |
| inverseEnergyGoal（R1） | 接受 | 正质量下p=M(M⁻¹p)，由E1恢复任意动量的速度总能量。 |

零维、零质量、负质量的代数边界和混合奇异质量反例由七个边界命题补充验证。物理正质量模型与Lean总除法扩展分别记录。本批不证明真实时间轨道等价、能量守恒、解存在唯一性、延拓或Theorem1.1。
