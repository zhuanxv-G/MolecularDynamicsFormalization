## Theorem 1.1：原页与可行证明路线

原页：印刷 32 / PDF 55。教材在定理前将 *strong local minimum* 定义为：存在邻域半径，在该邻域内除 `q*` 外均有 `U(q)>U(q*)`。对 `H(q,p)=1/2 pᵀM⁻¹p+U(q)` 的平衡 `z*=(q*,0)`，教材断言其 Lyapunov 稳定。教材只给出“足够近的轨道不能远离”的证明思路，并指向 [216]；这不是一个可直接移植的完整形式化证明。

建议证明分解如下，均是**待做的依赖任务**：

1. 假设配置空间为 `ℝ^{N_c}` 或包含 `q*` 邻域的开放域，`M` 为常数对称正定矩阵，`U` 在邻域内足够光滑，使 Hamiltonian 向量场局部 Lipschitz。若以对角质量表示，逐坐标假设 `0<mᵢ`。明确维数 `0` 的退化情况是否另处理。
2. 严格局部极小加可微性给出 `∇U(q*)=0`，故 `z*` 是平衡。现有 mathlib `IsLocalMin` 是非严格局部极小；不能单独作为课本的 strong local minimum。可用带去心邻域严格不等式的项目谓词。
3. 给定目标半径，取其内一条闭球面。有限维紧性和势能连续性使该球面上的 `U-U(q*)` 有严格正下界。这个“能量屏障”来自整条球面，不来自 Hessian 正定。
4. 初始相点足够接近 `z*` 时，能量严格低于屏障。由能量守恒和动能非负，轨道位置不能首次碰到球面。还须利用质量正定，把能量上界变成动量（或速度）界。
5. 因而正向轨道被困在配置开放域内部的紧集。用**局部解延拓定理**推出其在所有正时间存在，再得稳定性所要求的统一相空间邻域界。教材写的是 `sup_{t≥0} dist(F_t(z₀),z*) < ε`；只证明每一时刻 `dist<ε` 不足以保证上确界严格小于 `ε`，应在证明中先取更小的目标半径（如 `ε/2`）。若正式陈述只用局部流而不补延拓，就比教材结论弱。

这里的额外条件应与教材物理模型对照，不能悄悄放入结论的前提后仍称原定理完成。尤其要区分“势能严格局部极小”和“`U''(q*)` 正定”：后者只是一个更强的充分条件；例如 `U(x)=x⁴` 在 `0` 处严格极小而 Hessian 为零。

## 其他已定位的第一章断言与缺口

- 印刷 19 / PDF 42：教材的一行微分计算给能量守恒；同页的总动量守恒使用粒子间成对反作用力。现有抽象 `Force n` 不保证此对称性，需为相互作用模型单列条件。
- 印刷 20 / PDF 43：谐振子显式三角函数解是 ODE、能量守恒的测试模型。印刷 22–23 / PDF 45–46：Lagrangian `L=1/2 q̇ᵀMq̇-U(q)`、Euler–Lagrange 关系和坐标变换需要区分定义、变换公式与运动方程。
- 印刷 24 / PDF 47：教材写“`M(q)` 可逆”后求 Legendre 上确界。为使二次型上确界有限且在 `v=M(q)⁻¹p` 达到，需正定性；仅可逆不够。审计时应按物理质量正性补足并记录与原文措辞差异。
- 印刷 25–26 / PDF 48–49：能量下界首先控制动量，位置有界另需势能相关等值集/子水平集的有界性，接着才可能由局部解延拓推出全局解。教材此处给启发式论证，没有完整列出向量场局部 Lipschitz、开放域和紧集留在域内等条件。周期边界条件与奇异碰撞势需另建模型。
- 印刷 26 / PDF 49：流的逆映射和群律要求相应时间均有解、唯一性和时间平移；`Dynamics.Flow` 的连续全局群作用结构不能无证明地赋给仅局部解。
- 印刷 28 / PDF 51：第一积分是沿所有初值解保持常数的光滑函数；自治光滑场下对应 `∇I·f=0`。印刷 29 / PDF 52 的 Kepler 角动量守恒发生在避开原点的配置域，不能用整个 `ℝ²` 的光滑势表示。
- 印刷 31–32 / PDF 54–55：教材引用 Hartman–Grobman，注明 [177] 和 [362]；其“smooth, invertible”共轭措辞需要对照准确版本。常见双曲平衡结论给局部拓扑共轭，不能直接记录成一般的光滑共轭。此项是外部结果依赖，暂不作为已验证命题。
- 印刷 33 / PDF 56：正定 Hessian 可给 Theorem 1.1 的特例，但不是原定理假设。印刷 37 / PDF 60 把“处于势能极小”直接与正定 Hessian 相连，缺少非退化假设；不能据此建立通用引理。
- 印刷 44–45 / PDF 67–68：变分方程 `(1.10)` 要求流对初值可微，Lyapunov 指数还要求适当长期解及奇异值的上极限。图示轨道分离是数值证据，不是一般混沌定理。
- 印刷 35–36 / PDF 58–59：周期镜像势涉及有限截断与无限周期模型的区别；内点势能极小的 `∇U=0` 只是必要条件。印刷 39 / PDF 62 的中心力角动量守恒有边界条件限制，页脚明确提醒周期边界一般不保角动量。印刷 41–43 / PDF 64–66 的混沌条件和图形属于概念/实例层，不能据数值轨道推导普遍的遍历结论。
