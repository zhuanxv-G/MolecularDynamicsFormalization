本版本修复了 GitHub 上的公式渲染；数学内容与 book-ch01-08-summary 相同。

公式修复数量、符号表和待确认项见 [公式修复报告](BOOK_RENDER_FIX.zh-CN.md)。

主要入口：[本固定版本的全书审阅导航](https://github.com/zhuanxv-G/MolecularDynamicsFormalization/blob/book-ch01-08-render/docs/review/book/README.zh-CN.md)。版本：book-ch01-08-render。数学内容承接[第1–8章收口版本](https://github.com/zhuanxv-G/MolecularDynamicsFormalization/tree/book-ch01-08-closeout)。

## 建议阅读顺序

1. 先读[全书成果汇报](BOOK_SUMMARY_FOR_MENTOR.zh-CN.md)，了解结论、数量、可信度与待决定事项。
2. 再看[全书疑误索引](BOOK_ERRATA_INDEX.zh-CN.md)，选择优先裁定问题。
3. 按需查看各章SUMMARY、ERRATA及BLUEPRINT，逐项比对原句、假设、修正版和证明状态。
4. 规划下一阶段时看[未证与理论缺口](BOOK_GAPS.zh-CN.md)及[定义复用候选](BOOK_REDUNDANCY.zh-CN.md)。
