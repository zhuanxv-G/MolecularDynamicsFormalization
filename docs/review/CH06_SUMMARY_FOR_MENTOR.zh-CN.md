# 第6章：导师审阅摘要

教材为Leimkuhler–Matthews《Molecular Dynamics》（2015）第6章正文，印刷第211–258页，不含习题。249个条目的原文、数学陈述、证明和勘误对照已整理。

网站按各条最新送审版本直接通过203条。本轮复审60条的原始评价为25条通过、8条未通过、27条需人工判断；8条均已按意见处理并通过本地核验，修改后未再送网站。
27条需人工判断的复审条目中，22条另有获网站认可的修正版、限定陈述或反例。这些通过意见与原书疑误分别记录，不将整组计为未通过；也不将只给合格函数域的定义算成平均公式已证明。

勘误清单合并为32项原书疑误、论证缺口或范围待核问题，另列1项复密度代表的解释。详见[勘误清单](CH06_ERRATA.zh-CN.md)。相同的零时刻连续密度问题只计一次。OU方差根号、分部积分正号及定理6.2的κ为转录纠正，不计原书疑误。

数学材料共324个命名声明：123项定义、110项已证陈述、91项未证陈述。数量包含原文版、修正版、反例及辅助结论；定义不计作证明。
未证原因分为：原书疑误原文或限定摘录暂不证明21项；缺少大型理论或必要衔接结果52项；达到约定短证明尝试次数而停止18项。新列的两条L²范数恒等式尚待补证明；此处并不表示现有数学库缺少L²理论。

本轮将Fokker–Planck密度光滑性限制到正时间，避免确定初态与零时刻光滑密度矛盾；定理6.1保留闭实现与分布平均修正版，并把原域解释、严格负定和轨道时间平均的问题分别列出。定理6.2补实际生成元测试资格，引理6.1恢复原物理参数域并保留空集漏洞。另补两条L²范数陈述及分布平均恒等式；仅为核推进或测试函数域的定义仍明确注明所缺结论。

已验证：八项修改逐项单文件编译与全部声明依赖核对通过；固定Lean 4.34.0及对应Mathlib的完整检查通过。正式证明部分和第1–5章保持不变，正式证明部分没有未完成证明或新增公理。
尚待证明或裁定：91项未证陈述，以及导师对勘误、闭算子定义域和各项限定解释的裁定。八项本地修改未作再次网站审阅。
