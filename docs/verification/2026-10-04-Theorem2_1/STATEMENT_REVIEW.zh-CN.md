## 量词与符号

`E = Position m = EuclideanSpace ℝ (Fin m)` 使用欧氏范数。`f : E → E` 在开域 `D` 上满足 `ContDiffOn ℝ 1 f D`；域外值任意，不参与被证明留域的迭代。采用 total function 加 domain 的表示，与书中 `f : D → ℝᵐ` 的限定域表示对应。

`γ` 是给定真实精确解：`γ t ∈ D`，以及 `HasDerivWithinAt γ (f (γ t)) (Icc 0 τ) t`。端点使用区间内导数。初值为 `ξ = γ 0`，故 `eulerIterate f h (γ 0) 0 = ξ`。该误差估计对任意这样的解成立；书中唯一性假设无需额外使用，不将它替换为更强前提。

`h = τ / ν`，统一常数 `C > 0` 和阈值 `ν₀ > 0` 在 `ν` 之前量化。结论同时包含 `0 ≤ n ≤ ν` 的所有数值点留域与实际有限最大误差 `eulerMaxError ≤ C h`。`ν ≥ ν₀` 排除除零；`τ = 0` 分支单独证明。域的有界性在教材对应定理保留，但邻域证明给出对任意开域的更强辅助结果。

## 完整证明链

1. 由真实导数推出 `γ` 在 `[0,τ]` 连续，其像 `K` 紧。
2. `K ⊆ D`、`D` 开，推出存在 `r > 0`，闭 `r` 邻域包含于 `D`。有限维保证闭邻域仍紧。
3. C¹ 给出 `fderiv ℝ f` 连续；从紧邻域获得其统一范数界 `L > 0`。从轨道获得 `‖f(γ t)‖ ≤ M`。均值不等式推出每个中心 `γ t` 周围半径 `r` 的实际 Lipschitz 估计。
4. 链式法则给出 `(f ∘ γ)' = f'(γ) f(γ)`，范数不超过 `LM`。两次均值不等式给出真实 Euler 局部误差不超过 `A h²`，取 `A = LM > 0`。
5. 误差满足一步估计 `(1+hL)eₙ + A h²`。有限归纳用 `A h² n exp(nLh)` 作上界，统一小于 `A τ exp(Lτ) h`。归纳中从该误差与小步长推出仍在半径 `r` 邻域，不假设数值留域。
6. 取 `C = A τ exp(Lτ)`（正终时），用 Archimedean 性选出与 `ν` 无关的阈值，使所有 `ν ≥ ν₀` 均满足 `Ch ≤ r`。最后由所有节点估计控制实际有限最大值。
