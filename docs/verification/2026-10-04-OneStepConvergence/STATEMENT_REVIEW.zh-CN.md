# §2.2.3 稳定性、一致性和收敛的正文证明对应

- 教材定位：印刷66--67 / PDF88--89；原 PDF 渲染页已目视核对。式(2.9)--(2.12)及其后“consistent of order p and stable is convergent of order p”是此批目标。下一介绍性 Example 2.2 不计入本批，不冒充整节或整章完成。
- 形式化：`Chapter02/OneStepConvergence.lean` 中 `oneStepIterate` 是实际 `G_h` 的有限函数迭代，初值为精确曲线 `γ 0`；`oneStepMaxError` 是包括两个端点的实际有限最大值。
- 明确原文前提：精确曲线节点在 D，数值节点也在 D；正文把后者称为 simplifying assumption。这一前提在本节保留，而上一批 Theorem 2.1 已从 C¹ 开域条件独立导出 Euler 留域，不能混淆。
- 稳定性使用原(2.11)的 `(1+hL)` 因子；一致性使用原(2.10)的 `K h^(p+1)`，K≥0。式(2.12)分母要求 L>0；若已知非负 Lipschitz 系数，可先增大到任一正系数，仍满足稳定性。同一个正 L、非负 K 和正阈值 δ 必须独立于步数。
- 固定网格有限界对任意实阶 p 成立；最终收敛要求 p>0。正终时 τ 的网格 h=τ/ν 细化，ν=0 的总函数值不参与最终的 sufficiently-large 结论。终点 n=ν 被纳入最大值。
- 精确解的实际流关系 `Φ_h(γ t)=γ(t+h)` 已在沿曲线局部误差条件中展开；无需另加全局流、光滑数值映射或微分方程正则性假设。正文误差论证只使用这两个定量不等式。若由微分方程实例调用，仍须真实证明沿曲线的一致性条件。

## 完整证明路线

1. 从真实迭代公式取差，用三角不等式、稳定性和沿精确曲线的一致性推导误差递推；没有把这个递推作为教材目标的假设。
2. 令 d=(K/L)h^p，真实局部项满足 K h^(p+1)=h L d。有限归纳给出 e_n+d ≤ d(1+hL)^n。
3. 使用 1+hL ≤ exp(hL)，获得正文式(2.12)：e_n ≤ (K/L) exp(L n h) h^p。
4. 由 n h≤τ 取得独立于步数的系数 (K/L)exp(Lτ)，并据真实有限最大值给出全网格 p 阶误差界。
5. 对 ν→∞，h=τ/ν→0、h^p→0，用上下界夹逼证明实际最大误差趋于零；步长阈值只须最终满足。原(2.10)的严格 h<δ 与(2.11)的 h≤δ 分别保留。
